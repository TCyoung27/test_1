# 离线评估结果对比报告

本项目面向设施作物表型采集场景，智能体需要将自然语言任务转化为相机、机械臂、导航底盘和滑台等多类 MCP 工具的调用计划。由于真实硬件评估成本高、耗时长，并且存在设备状态、导航环境和安全风险等不确定因素，因此在真实执行前有必要先进行离线评估。离线评估不实际调用业务硬件工具，而是基于工具 schema、初始状态和技能说明，考察智能体框架下的模型在工具选择、参数生成、任务顺序规划和安全决策方面的能力。该评估结果可用于比较不同模型在作物表型采集智能体框架中的适配性，并为后续真实场景测试、Skill 优化和任务数据集扩充提供依据。

## 1. 数据来源

本报告基于 `results/1` 目录下两个模型各 3 次离线评估结果生成：

- `qwen-plus`
- `qwen3.5-plus`

每个模型均包含 3 次重复实验：

- `offline_eval_1`
- `offline_eval_2`
- `offline_eval_3`

统计数据来自各模型目录下的汇总 CSV：

- `qwen-plus/qwen-plus_offline_eval_summary.csv`
- `qwen3.5-plus/qwen3.5-plus_offline_eval_summary.csv`

评估数据集包括：

- `single_tool`
- `parameter`
- `safety`
- `simple_decision`
- `complex_decision`

## 6. 初步观察

1. 两个模型在 `single_tool` 和 `parameter` 数据集上表现接近，说明在单工具选择和明确参数提取任务中，低成本模型已经具备较高可用性。
2. `qwen3.5-plus` 在 `safety`、`simple_decision` 和 `complex_decision` 上提升明显，尤其在 `complex_decision` 中平均准确率提升 0.4275，`Pass^3` 提升 0.4491。
3. `qwen3.5-plus` 的平均单样本耗时约为 `qwen-plus` 的 5.94 倍，说明较强模型在复杂规划能力上有明显收益，但需要付出更高时间成本。
4. `complex_decision` 是两个模型差异最大的任务类型，适合作为后续论文中分析模型规划能力上限和失败模式的重点数据集。
5. `qwen-plus` 在 `complex_decision` 中 `AnyPass^3` 为 0.5509，高于 `Pass^3` 的 0.2963，说明该模型存在一定随机成功能力，但重复稳定性不足。
