# 离线评估结果汇总
离线评估基于工具 schema、初始状态和技能说明，考察模型在工具选择、参数生成、任务顺序规划和安全决策方面的能力。评估结果可用于比较不同模型在作物表型采集智能体框架中的适配性，并为后续真实场景测试、Skill 优化和任务数据集扩充提供依据。

以下两张表分别汇总 `qwen3.5-plus` 和 `qwen-plus` 在五类离线评估数据集上的三次重复实验结果。表中 `accuracy`、`duration`、`model_calls` 和 `load_skill` 均表示三次重复实验的平均值 ± 标准差；`accuracy`、`pass_3` 和 `any_pass_3` 以百分比表示；`duration` 为单条样本平均规划耗时，单位为秒；`model_calls` 和 `load_skill` 均为单条样本平均次数。

## 后续绘图提示

建议优先绘制以下图表，用于论文中更客观地展示模型能力差异：

1. 准确率分组柱状图：横轴为五类数据集，纵轴为 `accuracy_mean`，不同颜色表示模型，并加入标准差误差线。该图最适合作为主结果图，能直接体现不同模型在工具选择、参数生成、安全决策和复杂规划任务上的总体能力。

2. `pass_3` 与 `any_pass_3` 对比图：每个数据集绘制两组百分比指标，用于区分模型的稳定通过能力和三次实验中的可通过能力。如果 `any_pass_3` 明显高于 `pass_3`，说明模型具备偶发成功能力，但输出稳定性不足。

3. 准确率-耗时散点图：横轴为 `duration_mean`，纵轴为 `accuracy_mean`，点的颜色表示模型，点的形状或标签表示数据集。该图能展示“准确性-效率”权衡，尤其适合对比低端快速模型和中高端慢速模型在真实应用中的取舍。

4. 任务复杂度趋势图：按照 `single_tool -> parameter -> safety -> simple_decision -> complex_decision` 排列，分别绘制 accuracy 和 duration 的折线。该图可以表现随着任务从单工具识别到复杂多步骤规划，模型性能下降和推理成本上升的趋势。

5. 错误类型堆叠柱状图：后续如果整理 failed cases，可按工具选择错误、参数错误、顺序错误、安全策略错误、冗余调用等类别统计。该图适合支撑“模型失败原因分析”和后续 Skill 或提示词优化方向。
