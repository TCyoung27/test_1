# 离线评估结果汇总

本项目面向设施作物表型采集场景，智能体需要将自然语言任务转化为相机、机械臂、导航底盘和滑台等多类 MCP 工具的调用计划。由于真实硬件评估成本高、耗时长，并且存在设备状态、导航环境和安全风险等不确定因素，因此在真实执行前有必要先进行离线评估。离线评估不实际调用业务硬件工具，而是基于工具 schema、初始状态和技能说明，考察模型在工具选择、参数生成、任务顺序规划和安全决策方面的能力。该评估结果可用于比较不同模型在作物表型采集智能体框架中的适配性，并为后续真实场景测试、Skill 优化和任务数据集扩充提供依据。

以下两张表分别汇总 `qwen3.5-plus` 和 `qwen-plus` 在五类离线评估数据集上的三次重复实验结果。表中 `duration` 为单条样本平均规划耗时，单位为秒；`model_calls` 和 `load_skill` 均为单条样本平均次数。
